# Task 3: Facility Data Analysis

## Description

This project analyzes facility data using Python to identify missing values, duplicate records, invalid data, and outliers.

## Features

* Data cleaning and preprocessing
* Missing and duplicate value detection
* Invalid data and outlier detection
* Statistical analysis
* Data visualization using charts

## Visualizations

* 2 Bar Charts
* 1 Histogram
* 1 Scatter Plot
* 1 Additional Visualization

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

The dataset contains facility information such as location, cleanliness score, odor score, waste level, water availability, footfall, complaints, and inspection date.

## How to Run

1. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn`
2. Run the Python file:
   `python analysis.py`

## Output

The project generates statistical summaries, data quality reports, insights, and visualizations.
